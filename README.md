Entry for the [make.fun bounty "Till Firmware Do Us Part"](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929) — a single wedding vow a robot says at its own wedding, one sentence under 200 characters, funny and heartfelt at the same time.

## Run

```sh
python3 main.py
```

Writes the vow to `/output/entry.txt` and prints it to stdout. No network, no dependencies, deterministic.
